## 强制规则

- mutation 的数据库条件必须包含 owner/participant，不先查询后无条件按 ID 更新。
- 公开接口只返回 Public DTO，不能复用私有详情实体序列化。
- 管理员能力不通过普通资源 procedure 隐式获得，使用独立、可审计命令。
- 资源不存在和无权访问对非参与者统一返回 `NOT_FOUND`，减少枚举攻击。
- 接受应聘、确认预约、容量扣减和状态更新必须在同一事务内并使用幂等键。
