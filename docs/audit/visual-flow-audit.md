## 最高影响问题

1. P0：需求发布移动端布局不可用；正式接线前必须先修复响应式壳和卡片最小宽度。
2. P0：服务者页是 mock 且语言混排，不能作为公开服务市场上线。
3. P0：未登录 Dashboard 是死胡同，应进入登录/注册并保存 returnTo。
4. P1：公开需求页面需要响应式网格、明确价格含义和统一语言来源。
5. P1：首页示例数据与真实市场区分不足；应标“示例”或接真实公开 DTO。
