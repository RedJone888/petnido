# T01 缺失页面与交互清单

## P0：首个可用闭环必须补齐

- 首次注册资料完善、意图选择、服务档案创建引导。
- 服务公开列表、服务详情、服务者公开档案。
- 真实应聘、预约、确认/拒绝/撤销页面和状态反馈。
- 会话列表与会话详情；由应聘/预约动作原子创建会话。
- 个人资料、宠物档案、地图位置管理。
- 发布成功后的匹配推荐和无精确匹配时的降级推荐。
- 邮件通知偏好与未开启提示。
- 认证失败、验证码验证、会话过期、无权限和资源不存在状态。

## P1：MVP 完整性

- 收藏列表；公开页隐藏过期需求但收藏保留并标注过期。
- 寄养容量日历与已有成功预约宠物数。
- 服务单项开关、全部开关、批量地点/币种更新。
- 照护知识分类列表与外链详情。
- 三语言的空状态、错误、邮件模板和元数据。

## 横切交互缺口

- 登录前动作只保存 URL，尚不能恢复“收藏/咨询/应聘/预约”的动作参数。
- 页面按钮多处仅切换本地状态，没有服务端事实来源或幂等保护。
- 对状态变化缺少并发冲突提示、撤销影响说明和操作审计。
- 地点输入仍可能携带精确地址文本，与“不保存精确地址”冲突。
- 金额未形成统一的整数最小货币单位、币种、计价单位契约。
- 缺少加载骨架、重试、部分失败和离线草稿策略的一致规范。
- 无障碍焦点、键盘流程、错误摘要和多语言长度尚未系统验收。

- [x] P0/P1 分级可直接进入开发排期。
